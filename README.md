# Accessible Path

Accessible Path is a mobility-aware navigation application designed to help users find pedestrian routes based on accessibility requirements.

The project will explore geospatial data, graph algorithms, accessibility-aware routing, and full-stack web development.

## Planned Concepts

- React
- Node.js / Express
- PostgreSQL
- PostGIS
- OpenStreetMap data
- Geospatial queries
- Graph data structures
- Dijkstra / A* routing
- Accessibility constraints
- REST APIs
