# Accessible Path

Accessible Path is a mobility-aware navigation application designed to help users find pedestrian routes based on accessibility requirements.

The project will explore geospatial data, graph algorithms, accessibility-aware routing, and full-stack web development.
# Initial Project Goal

The initial goal of Accessible Path is:

Build a system capable of finding a pedestrian route between two locations within a limited geographic area while avoiding physical barriers that conflict with a user's mobility requirements.

## Planned Concepts

- React
- Node.js / Express
- PostgreSQL
- PostGIS
- OpenStreetMap data
- Geospatial queries
- Graph data structures
- Dijkstra / A* routing
- Accessibility constraints
- REST APIs
